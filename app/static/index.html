    01

    Mandate, not a blank cheque

    The agent parses budget, category, per-transaction and daily limits plus a human-approval threshold. Hard rules cannot be overridden by an approval.

    02

    Authorize first, release later

    PayPal Orders authorize the job total up front. Funds are held, not captured. Each milestone is a partial capture after verification passes.

    03

    Evidence over vibes

    Deterministic file inspection checks dimensions, palette, transparency, placeholders and licence language. An optional model adds qualitative judgment — never a veto over hard failures.

    04

    Payouts with a receipt

    The freelancer's share goes out via PayPal Payouts. The audit log is SHA-256 hash-chained, and the demo includes a tamper test to prove it.
